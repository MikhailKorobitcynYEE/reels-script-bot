# 🎬 Бот-сценарист Reels

Telegram-бот, который пишет сценарии вирусных Reels для Instagram по авторской методичке: задает анкету из 8 вопросов, анализирует ответы и выдает полный сценарий — хук, развитие, усиление, финал с CTA, советы по съемке, варианты подписи, разбор алгоритмов и альтернативные заходы.

Внутри работает Perplexity API (модель выбирается в настройках, по умолчанию Claude Sonnet).

## Как работает бот

1. Пользователь отправляет `/start` — бот здоровается и присылает анкету из 8 вопросов.
2. Пользователь отвечает развёрнуто — одним сообщением или по частям, бот всё запоминает.
3. Пользователь отправляет `/done` — бот пишет сценарий: разбор ответов → хук, развитие, усиление, финал с CTA → как снять → 2–3 варианта подписи → почему это работает → альтернативные заходы.
4. Дальше сценарий можно дорабатывать прямо в чате: «сделай хук жёстче», «перепиши под сторителлинг» — бот помнит контекст диалога.
5. `/new` — начать новый сценарий с чистого листа.

Бот с включённым веб-поиском (по умолчанию) проверяет актуальные тренды и алгоритмы Instagram в интернете — советы не берутся «из памяти» модели и не устаревают.

Команды:

| Команда | Что делает |
|---|---|
| `/start` | приветствие + анкета из 8 вопросов |
| `/new` | новый сценарий (сбрасывает диалог) |
| `/done` | «я ответил на всё, пиши сценарий» |
| `/help` | как пользоваться ботом |
| `/about` | что умеет бот и какая модель внутри |

## Установка (5 минут)

Нужен Python 3.10+ (проверить: `python --version`).

### Шаг 1. Создайте бота в Telegram

1. Откройте [@BotFather](https://t.me/BotFather)
2. Отправьте `/newbot`, выберите имя и username
3. Скопируйте токен вида `1234567890:AAF...`

### Шаг 2. Получите ключ Perplexity API

1. Зайдите на [perplexity.ai/settings/api](https://www.perplexity.ai/settings/api)
2. Создайте API-ключ (начинается с `pplx-`)

### Шаг 3. Настройте и запустите

```bash
# 1. Установите зависимости
pip install -r requirements.txt

# 2. Создайте файл настроек из шаблона
cp .env.example .env        # Windows: copy .env.example .env

# 3. Откройте .env в любом редакторе и вставьте:
#    BOT_TOKEN  — токен от BotFather
#    PPLX_API_KEY — ключ Perplexity

# 4. Запустите бота
python bot.py
```

Если в консоли появилось `Бот запущен. Модель: ...` — всё работает, открывайте своего бота в Telegram и пишите `/start`.

## Выбор модели

По умолчанию `anthropic/claude-sonnet-5`. Другие варианты:

- `openai/gpt-5.6-sol` — сильная альтернатива
- `perplexity/sonar` — дешевле, с поиском по вебу (актуальные тренды Instagram)

Посмотреть все модели, доступные именно вашему ключу:

```bash
python list_models.py
```

Затем впишите нужную в `.env` в переменную `MODEL`.

Важно: для моделей `anthropic/*` обязателен параметр `max_output_tokens` — бот передает его автоматически (`MAX_OUTPUT_TOKENS` в `.env`, по умолчанию 8000).

## Настройки (.env)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | — | токен от @BotFather (обязательно) |
| `PPLX_API_KEY` | — | ключ Perplexity API (обязательно) |
| `MODEL` | `anthropic/claude-sonnet-5` | модель-сценарист |
| `MAX_OUTPUT_TOKENS` | `8000` | максимальная длина ответа |
| `TEMPERATURE` | пусто | творческость модели (0–2); пусто = не отправлять (Anthropic-модели через этот API не принимаtemperature) |
| `ENABLE_WEB_SEARCH` | `true` | проверять ли тренды Instagram через веб-поиск |
| `MAX_STEPS` | `3` | сколько шагов поиска делает модель |
| `HISTORY_LIMIT` | `24` | сколько последних сообщений диалога помнит бот |
| `HEALTHCHECK_PORT` | `8080` | порт для проверки живости бота (для деплоя) |

## Структура проекта

```
reels-script-bot/
├── bot.py                  # логика Telegram-бота (aiogram 3)
├── perplexity_client.py    # клиент Perplexity Agent API
├── utils.py                # разбивка длинных ответов на сообщения Telegram
├── list_models.py          # список доступных моделей для вашего ключа
├── prompts/
│   └── system_prompt.txt   # методичка сценариста (системный промпт)
├── tests/
│   └── test_split.py       # тесты разбивки сообщений
├── requirements.txt        # зависимости
├── .env.example            # шаблон настроек
└── README.md
```

Хотите поменять поведение сценариста — редактируйте `prompts/system_prompt.txt` и перезапустите бота: файл перечитается при старте.

## Запуск на постоянной основе

Пока запущен `python bot.py` — бот онлайн. Варианты для работы 24/7:

- **Свой сервер / VPS**: `systemd`-сервис или `screen`/`tmux`
- **Railway, Render, Fly.io**: у них есть бесплатные тарифы для Python-ботов

Минимальный пример для systemd:

```ini
[Unit]
Description=Reels Script Bot
After=network.target

[Service]
WorkingDirectory=/path/to/reels-script-bot
ExecStart=/usr/bin/python3 bot.py
Restart=always

[Install]
WantedBy=multi-user.target
```

## Частые проблемы

| Ошибка | Решение |
|---|---|
| `Не задан BOT_TOKEN` | создайте `.env` из `.env.example` и вставьте токен |
| `API отклонил ключ (401/403)` | проверьте `PPLX_API_KEY`, ключ должен начинаться с `pplx-` |
| `Модель не найдена (404)` | запустите `python list_models.py` и впишите корректный `MODEL` |
| `Слишком много запросов (429)` | исчерпан лимит запросов, подождите минуту |
| Бот молчит после ответов | сначала отправьте `/done`; генерация сценария занимает 1–3 минуты, статус «Пишу сценарий...» — это нормально |
| Бот «забыл» диалог | история хранится в памяти и сбрасывается при перезапуске — это нормально для MVP |

## Стоимость

Perplexity API оплачивается по токенам. Один полный сценарий с разбором и альтернативами — это ориентировочно несколько тысяч токенов, копейки в долларах при разовом использовании. Актуальные тарифы: [perplexity.ai/settings/api](https://www.perplexity.ai/settings/api).
