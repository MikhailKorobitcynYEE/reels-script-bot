# 🚀 Переносим бота на бесплатный круглосуточный сервер

Бот переедет на **Render** (бесплатный тариф) — он будет работать 24/7 без вашего компьютера. Нужны только браузер и 15 минут. Командная строка не нужна вообще.

Из вашего прошлого архива в новую папку для GitHub **нельзя** класть файл `.env` и файлы `.log` — там ключи. Чистый архив для выкладывания называется `reels-deploy.zip`, в нём ключей нет.

## Шаг 1. Выкладываем код на GitHub (5 минут)

GitHub — это просто «флешка в интернете», откуда Render возьмёт код бота.

1. Зайдите на [github.com](https://github.com). Если аккаунта нет — **Sign up** (email, пароль, всё как обычно)
2. Нажмите зелёную кнопку **Create a new repository** (или «+» в правом верхнем углу → New repository)
3. В поле **Repository name** напишите: `reels-script-bot`
4. Выберите **Private** (закрытый репозиторий)
5. Нажмите **Create repository**
6. На открывшейся странице найдите ссылку **uploading an existing file** и нажмите её
7. Распакуйте `reels-deploy.zip` на компьютер, откройте папку и **перетащите мышкой все файлы и папки** из неё в окно GitHub (там будет большая область «Drag files here»). Папки `prompts` и `tests` тоже перетащите целиком
8. Дождитесь, пока файлы загрузятся, и нажмите зелёную кнопку **Commit changes**

Проверьте себя: в списке файлов должны быть `bot.py`, `render.yaml`, папка `prompts` и другие. Файла `.env` быть **не должно**.

## Шаг 2. Запускаем бота на Render (5 минут)

1. Зайдите на [render.com](https://render.com) и нажмите **Get Started for Free**
2. Выберите **Sign in with GitHub** — аккаунт GitHub, который создали в шаге 1
3. После входа нажмите **New +** (синяя кнопка вверху) → **Blueprint**
4. Render покажет ваш репозиторий `reels-script-bot` — выберите его и нажмите **Apply**
5. Render спросит значения двух переменных — впишите их:
   - **BOT_TOKEN** — токен бота от BotFather (`8713053804:AAH...`)
   - **PPLX_API_KEY** — ключ Perplexity (`pplx-...`)
6. Нажмите **Apply / Save** и подождите 2–3 минуты, пока идёт сборка

Готово, когда вверху страницы статус **Live** (зелёный). Бот уже работает.

## Шаг 3. Не даём боту заснуть (3 минуты)

Бесплатный Render усыпляет бота, если к нему 15 минут нет обращений. Чтобы он работал круглосуточно, настроим бесплатный «будильник»:

1. Зайдите на [uptimerobot.com](https://uptimerobot.com) → **Register** (бесплатно)
2. После входа нажмите **Add New Monitor**
3. Заполните:
   - **Monitor Type**: HTTP(s)
   - **Friendly Name**: reels bot
   - **URL (или IP)**: адрес вашего бота с Render — вида `https://reels-script-bot-xxxx.onrender.com` (скопируйте его со страницы сервиса на Render, ссылка вверху)
4. Проверьте, что **Monitoring Interval**: 5 minutes
5. Нажмите **Create Monitor**

Теперь «будильник» пингует бота каждые 5 минут, и Render его не усыпит.

## Шаг 4. Проверка

Откройте вашего бота в Telegram и отправьте `/start`. Если он ответил анкетой — всё работает. Напишите мне, что бот переехал, — я выключу временную копию, которая работала из моей среды (иначе они будут конфликтовать).

## Что важно знать про бесплатный тариф

- **Без гарантий**: это бесплатный сервис, иногда он может перезапускаться. После перезапуска бот поднимется сам за минуту-другую
- **Диалоги сбрасываются при перезапуске** — если посреди работы над сценарием бот перезапустился, просто начните заново с `/new`
- **Лимит 750 часов в месяц** — для одного бота, работающего круглосуточно, хватает (в месяце максимум 744 часа)
- Если когда-нибудь захотите надёжнее и без ограничений — на Render есть платный тариф за несколько долларов в месяц, переключение в два клика

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| Render показывает ошибку при сборке | напишите мне, пришлите текст ошибки со страницы Events / Logs |
| Статус Live, но бот молчит в Telegram | возможно, конфликт: скажите мне — я выключу свою копию, и через минуту бот оживёт |
| Неверный BOT_TOKEN/PPLX_API_KEY | на Render: слева Configuration → Environment → поправьте значение → Save Changes (сервис перезапустится сам) |
| Хочу поменять модель или настройки | там же в Environment добавьте переменную (например `MODEL` = `openai/gpt-5.4-mini`) → Save |
